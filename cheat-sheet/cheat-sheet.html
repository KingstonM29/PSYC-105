Ch 8: Language, structural features

  • Phoneme = smallest unit of sound. chairs = /ch/ /ai/ /r/ /s/ (6 letters, 4 sounds). cats = /k/ /a/ /t/ /s/. unlocked = /u/ /n/ /l/ /o/ /k/ /t/ (ck = 1 sound, -ed sounds like /t/). Count sounds, not letters.
  • Morpheme = smallest unit of meaning (whole word, prefix, suffix). chairs = (chair)(s) = 2, -s = plural. cats = (cat)(s). unlocked = (un)(lock)(ed) = 3: un- = reverse/not, -ed = past tense.
  • Syntax = rules for ordering words into sentences (grammar). "Dog bites man" vs "Man bites dog": same words, different meaning.
  • Extralinguistic information = meaning from outside the words: tone of voice, facial expression, gestures, context. Ex: sarcastic "Great job" means the opposite; "Can you pass the salt?" is a request, not a question about ability.
  • Order of size: phonemes build morphemes, morphemes build words, syntax arranges words into sentences, extralinguistic info adds meaning around them.

Ch 8: Properties of language

  • Generative: a finite set of sounds/words combines into an unlimited number of new sentences that others understand. Ex: you can say a sentence nobody has ever said and be understood.
  • Arbitrary / symbolic: words don't resemble what they mean ("cat" doesn't look/sound like a cat); the link is a shared convention. Ex: dog / chien / perro all mean the same animal.
  • Specialized brain areas: usually left hemisphere; Broca's area (speech production), Wernicke's area (comprehension).
  • Developmental stages: language is learned in a predictable sequence (babbling, first words, combining words). Deaf babies show manual babbling (repetitive hand shapes, ~9 months), just like vocal babbling in hearing babies.

Ch 8: Sign language (gesture activity)

  • Activity: groups took turns as signer, data recorder and message recipient, guessing sentences from made-up gestures.
  • It was hard because it's hard to invent a sign for many words, and we don't already know the correct ASL sign for each word.
  • True sign languages (ASL) are real languages: same structural features as spoken language (units, meaning pieces, syntax); signs are generally arbitrary and symbolic (not pantomime, so you can't guess them); generative; same developmental stages (manual babbling); use the same specialized brain areas.
  • Common wrong answer: "signs are just gestures that look like the thing." Most signs are arbitrary.

Ch 8: WAIS-IV (Wechsler Adult Intelligence Scale)

4 index scores combine into overall (full-scale) IQ:

  • Verbal Comprehension: Similarities (how are 2 things alike, e.g., apple and banana), Vocabulary (define words), Information (general knowledge, e.g., capital of a country).
  • Perceptual Reasoning: Block Design (copy a red/white pattern with coloured blocks), Matrix Reasoning (pick the piece that completes a pattern grid), Visual Puzzles (pick pieces that build a shape).
  • Working Memory: Digit Span (repeat number strings forward/backward), Arithmetic (math word problems in your head).
  • Processing Speed: Symbol Search (find target symbols in a row fast), Coding (copy symbols matched to numbers, timed).

Memory: V P W S. Verbal + Perceptual have 3 subtests each; Working Memory + Speed have 2 each.

Quick ID: holding/manipulating info in mind = working memory; doing simple tasks fast = processing speed; visual/spatial patterns = perceptual reasoning; words/knowledge = verbal comprehension.

Ch 8: Class "IQ test" activity

  • Q1 letters (A-P) = working memory. Q2 copy symbols using number key = processing speed. Q3 how many legs: Deacon, Pickerel, Manx, Weimaraner, Chesterfield = verbal/vocabulary, BIASED: not common words. Q4 mental math = arithmetic/working memory. Q5 cross out shapes/numbers by spoken rules = perceptual/working memory. Q6 fill in number series = working memory. Q7 unscramble "leg flies one have only" = verbal/syntax, BIASED: some ambiguity (flies have more than one leg). Q8 complete X O X X O X pattern = perceptual reasoning. Q9 count cubes in figures A-D = perceptual reasoning (ambiguity in figures). Q10 overlapping shapes = working memory.
  • Questions read only once, under heavy time pressure.
  • Sources of test bias: (1) unfamiliar vocabulary or cultural knowledge, (2) ambiguous wording or figures, (3) time pressure / test conditions. A biased test measures background or conditions instead of ability.

Ch 8: Army Beta IQ test (1917)

  • Picture-based test for WWI U.S. Army recruits who couldn't read English (Army Alpha was the written version). Test 6: find the missing part of drawings (bowling alley, tennis court, phonograph, playing card, light bulb).
  • Lesson: non-verbal does not mean culture-free; you need cultural experience with the objects, so it was still biased.

Ch 8: What should IQ tests measure?

  • Most modern IQ tests focus on cognitive abilities (like the 4 WAIS-IV indexes).
  • Some researchers argue other factors should be included (e.g., creativity, practical/everyday problem solving, emotional skills).

Short answer: correlation template

Ex: more coffee = more anxiety. Scatterplot: positive slope (dots rise left to right) = 1; label X = coffee consumption, Y = anxiety (1/2 each).

  • (1) Causal: coffee causes anxiety.
  • (1) Reverse causal: anxiety causes more coffee drinking.
  • (1) Third variable (name a specific one): lack of sleep causes both more coffee and more anxiety.

Positive = both rise together. Negative = one rises as the other falls (dots fall left to right). No correlation = no pattern. Correlation does not prove causation.

Textbook extras: Ch 8 (not on slides; check study guide)

Thinking

  • Concept = mental category of similar things. Prototype = best/most typical example (robin for "bird").
  • Algorithm = step-by-step procedure that guarantees a solution (slow). Heuristic = mental shortcut (fast, error-prone).
  • Availability heuristic: judge likelihood by how easily examples come to mind (fear of plane crashes). Representativeness heuristic: judge by how well something matches a prototype, ignoring base rates.
  • Confirmation bias: seek info that supports what you already believe. Belief perseverance: keep beliefs after they're disproven.
  • Functional fixedness: only see objects' usual use. Mental set: stick with a strategy that worked before. Framing: wording changes decisions (95% survive vs 5% die).
  • Insight = sudden "aha" solution.

Language development

  • Cooing (~2 mo), babbling (~4-6 mo, all phonemes, then narrows to native language), one-word stage (~12 mo), two-word / telegraphic speech (~18-24 mo, "want milk"), full sentences.
  • Overregularization: applying grammar rules too widely ("goed", "mouses"), shows kids learn rules, not just imitation.
  • Critical/sensitive period: language learned most easily early in life.
  • Linguistic relativity (Sapir-Whorf): language shapes thought; weak version (influences) is supported, strong version (determines) is not.

Intelligence theories and testing

  • Spearman's g: one general intelligence underlies all abilities (scores on different tests correlate) + specific abilities (s).
  • Fluid intelligence = reasoning/solving new problems (declines with age). Crystallized = accumulated knowledge/vocabulary (stable or rises).
  • Gardner's multiple intelligences: linguistic, logical-mathematical, spatial, musical, bodily-kinesthetic, interpersonal, intrapersonal, naturalist.
  • Sternberg's triarchic theory: analytical, creative, practical intelligence.
  • Emotional intelligence: perceive, use, understand and manage emotions.
  • Binet: mental age. Stern's ratio IQ = mental age / chronological age x 100. Modern deviation IQ: mean 100, SD 15; 68% score 85-115, 95% score 70-130.
  • Standardization = same procedures + norms from a representative group. Reliability = consistent scores (test-retest). Validity = measures what it claims to (predicts school performance).
  • Flynn effect: average IQ scores rose ~3 points per decade. Stereotype threat: worry about confirming a stereotype lowers performance.
  • Heritability describes variation in a group, not one person; environment still matters.

Ch 11: 3 ways to define/measure stress

1. Stress as a STIMULUS (stressors = things that stress us out)

  • Social Readjustment Rating Scale (SRRS): 43 major life events (yes/no), each with points (life change units). Death of spouse 100, divorce 73, marital separation 65, jail term 63, death of close family member 63, personal injury/illness 53, marriage 50, fired at work 47, marital reconciliation 45, retirement 45, change in health of family member 44, pregnancy 40, death of close friend 37, begin or end school 26, change in residence 20, vacation 13, Christmas 12, minor violations of the law 11.
  • Positive events (marriage, vacation) count too: any change requires readjustment.
  • Daily Hassles Scale: everyday annoyances rated 0 / 5 / 10: missing the bus, conflicts between job and college, library too noisy, housemate too noisy, preparing meals, too little time, too little money, deciding what to wear, laundry, materials unavailable in library, getting up in the morning, my weight, not enough time to exercise, noisy neighbours.
  • Major issue: measuring the events that happen to people doesn't tell us how stressed they felt about them.

2. Stress as a RESPONSE (how we react)

  • 4 parts: thoughts (worry, racing mind), feelings (anxious, irritable), behaviours (e.g., procrastinating), physical sensations (pounding heart).
  • Stress mobilizes energy for fight or flight (sympathetic nervous system).
  • Measures (physiological): heart rate (watch, finger clip), blood pressure (cuff), galvanic skin response (finger electrodes, sweat/skin conductance), hormones (cortisol) from blood or saliva.
  • Major issue: physical changes could be caused by things other than stress (e.g., excitement); they don't show how the person is interpreting those sensations.

3. Stress as a TRANSACTION

  • Stimulus + Appraisal = Response: event + "how well can I handle it?" = how stressed you feel.
  • Stress = too many demands, too few resources (seesaw). Ex: demands = many assignments; resources = very little time; result = STRESS.
  • Fixes the earlier problems: it includes the person's own appraisal.
  • Measure: Perceived Stress Scale (PSS): 10 items, feelings and thoughts in the last month, rated 0 never, 1 almost never, 2 sometimes, 3 fairly often, 4 very often. How often have you: (1) been upset because something happened unexpectedly; (2) felt unable to control the important things in your life; (3) felt nervous and "stressed"; (4) felt confident about your ability to handle personal problems; (5) felt things were going your way; (6) found you could not cope with all the things you had to do; (7) been able to control irritations in your life; (8) felt you were on top of things; (9) been angered by things outside your control; (10) felt difficulties were piling up so high you could not overcome them. Items 4, 5, 7, 8 are positively worded (reverse scored).

Summary: Stimulus = SRRS, Daily Hassles (issue: no feelings). Response = HR, BP, GSR, cortisol (issue: not specific to stress, no interpretation). Transaction = PSS (stimulus + appraisal).

Ch 11: Appraisal (ex: car breaks down)

  • EVENT leads to Primary appraisal: Is this situation a threat? What are the demands? If no: carry on, no stress. If yes: go to secondary appraisal.
  • Secondary appraisal: How well can I cope? What are my resources (time, money, skills, support)? Minimal resources = STRESS. Many resources = less stress, then choose coping.

Ch 11: Ways of coping

  • 1. Problem-focused: change the SITUATION. Ex: call a tow truck; ask coworker to cover shift; make a to-do list; ask family to help move; look over notes before quiz.
  • 2. Emotion-focused: change your REACTION. Ex: deep breathing, change your focus, cognitive reappraisal (think about it differently: "it's only 5%", "my friend will understand", "the new job is exciting").
  • 3. Proactive: act in advance to PREVENT future stressors. Ex: regular car maintenance; put quiz dates in calendar on day 1; start cheat sheet a week early; cloud backups.
  • Can't change the situation: emotion-focused helps right now. Want a different outcome: need problem-focused. Big/complex stressors: need both.

Ch 11: Individual differences

  • People perceive different amounts of stress for the same situation (see the different ratings above).
  • Affects wellbeing: some feel better at exam time, or feel excited rather than terrified by big life changes.
  • To reduce stress: emotion-focused (think of the situation differently) + proactive (organized, prepared, so you're ready for more).
  • Downside of low stress: stress helps us focus on important events/tasks; without it you might not change or improve.

Ch 11: Diaphragmatic breathing

  • Activates the parasympathetic nervous system (rest and calm) via the vagus nerve. It is emotion-focused (changes your reaction).
  • How: (1) sit, both feet flat; (2) one hand on chest, one on belly below ribs (diaphragm); (3) inhale for 3, belly extends, chest and shoulders still; (4) exhale for 5, slow steady stream, push all air out; (5) focus on breathing, not stressful thoughts.

Textbook extras: Ch 11 (not on slides; check study guide)

  • Lazarus and Folkman = transactional model / appraisal. Holmes and Rahe = SRRS (300+ life change units in a year = high illness risk). Cohen = PSS.
  • Selye's General Adaptation Syndrome: alarm (fight or flight kicks in), resistance (body copes, stays aroused), exhaustion (resources depleted, illness more likely).
  • SAM pathway (fast): sympathetic nervous system, adrenal medulla, adrenaline/noradrenaline. HPA axis (slower): hypothalamus, pituitary (ACTH), adrenal cortex, cortisol.
  • Tend and befriend (Taylor): response of nurturing and seeking social support, especially in women.
  • Acute stress = short-term; chronic = long-term, harms health. Eustress = positive stress; distress = negative.
  • Yerkes-Dodson law: moderate arousal = best performance; too little or too much hurts (links to "downside of low stress").
  • Psychoneuroimmunology: chronic stress suppresses the immune system (slower healing, more colds).
  • Type A (competitive, impatient, hostile; hostility linked to heart disease) vs Type B (relaxed).
  • Hardiness: commitment, control, challenge. Optimism, perceived control and social support buffer stress.
  • Other coping: avoidance (helps short-term, hurts long-term), rumination (dwelling, increases stress), exercise, sleep, mindfulness/meditation, humour.

Quick MC traps

  • Sounds = phoneme; meaning = morpheme; word order = syntax; tone/face/context = extralinguistic.
  • Digit Span/Arithmetic = Working Memory (not Speed). Coding/Symbol Search = Processing Speed. Block Design/Matrix = Perceptual.
  • SRRS + Daily Hassles = stimulus. HR/BP/GSR/cortisol = response. PSS = transaction.
  • "Is it a threat?" = primary. "Can I cope?" = secondary.
  • Tow truck = problem. Reappraisal/breathing = emotion. Maintenance/calendar ahead of time = proactive.
  • Parasympathetic = calming (breathing). Sympathetic = fight or flight.
  • Missing the bus = daily hassle. Moving cities/new job = major life event.
